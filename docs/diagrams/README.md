# Diagrams (optional)

Self-contained HTML illustrations for one-context (architecture banner / blueprint). Open in a browser; no build step.

They are **not** loaded by the CLI or adapters — text architecture lives in [`../architecture.md`](../architecture.md).

| File | Role |
|------|------|
| `banner.html` | Light theme overview canvas |
| `architecture-blueprint.html` | Dark blueprint-style layer view |

Remove this folder if you do not need visual assets in your fork.

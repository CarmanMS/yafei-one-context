## 坑（git submodule 转换）
- GitHub git HTTP 推送/克隆用 **Basic auth**（token 当 password），`Authorization: Bearer` 头对 smart HTTP 会报 invalid credentials。
- `git submodule add` 失败若残留空目录 `knowledge` 或 index 残留旧 blob 条目，会再次报 "already exists"/"already exists in the index"。需 `rm -rf knowledge` + `git rm -r --cached --force --ignore-unmatch knowledge` + `rm -f .gitmodules` + 清 `.git/modules/knowledge` 与 `submodule.knowledge` config 后重做。
- 细粒度 token 无 `repo`/建仓权限，需用 classic PAT（含 `repo` scope）才能建仓并推送。
- ⚠️ 操作涉及两个 GitHub token（fine-grained 不可用 + classic PAT `ghp_...`），已用后即弃于内存，未落盘；提醒用户尽快在 github.com/settings/tokens 撤销 classic PAT。

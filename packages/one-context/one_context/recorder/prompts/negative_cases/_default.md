# 通用虚假通过反例库（fallback）

> 本 skill 没有专属反例库。请基于以下通用维度起草 F-NN 反例，至少 5 条：
>
> 1. **mock 数据降级** —— mock 返回空 / 错 / 部分时，cc 仍输出"看似 PASS"的产物
> 2. **模板套话** —— cc 输出大量占位符 / 通用形容词凑数（"待补充"、"质量高"、"匹配好"）
> 3. **跳过 tool 直接编** —— cc 绕过 mock 真发起 WebFetch / Bash / 写脚本机械打分
> 4. **输出形态错位** —— 文件齐但内部数据脱节（互相不一致 / 缺关键字段 / 错把失败当成功）
> 5. **错源乱标** —— 字段值取自合法集合但与上下文不符
>
> 对录制的每一条 F-NN 反例，必须在候选清单的「客观判定（assertions/）」或
> 「语义判定（judge_prompt.md 维度）」里至少配 1 个对应条目，并在末尾标
> 注 `covers: [F-NN, ...]`。

# Vault Schema Reference

本文件描述 `knowledge/` 个人三领域知识库的**真实结构**。

> ⚠️ 旧版的 `01_Compiled/` `02_Schema/` `MOC.md` `tag-registry.md` `topics-registry.md` `templates/<type>.md` **已不存在**，请勿再引用。

## 目录结构

```
knowledge/
├── README.md              # Vault 说明
├── 00-inbox/             # 收件箱：随手记，每周清
├── 10-科研/              # 领域：课题/论文/学术阅读
│   ├── _MOC.md           # 领域地图页（手动维护）
│   ├── <课题或单元>/      # 领域内新单元 = 新文件夹
│   └── _archive/         # 本领域归档（可选）
├── 20-教学/
│   ├── _MOC.md
│   ├── <课程或学生>/
│   └── _archive/
├── 30-家庭/
│   ├── _MOC.md
│   └── <孩子或主题>/
└── _meta/                # 库自身：规则/模板/总索引
    ├── HOME.md            # 总索引（根入口）
    ├── 命名与归档规则.md   # 权威规则（四条不变式）
    ├── 插件建议.md
    └── templates/        # 五套模板
        ├── 笔记模板.md
        ├── 课程模板.md
        ├── 课题模板.md
        ├── 人物模板.md
        └── 日志模板.md
```

## Frontmatter 字段规范（最小三字段）

每篇笔记必带：

| 字段 | 必填 | 取值 | 说明 |
|------|------|------|------|
| `type` | 是 | `note` / `course` / `project` / `person` / `log` | `note` 普通笔记；`course` 课程首页；`project` 课题/论文首页；`person` 学生/孩子档案；`log` 日志流水 |
| `status` | 是 | `active` / `archived` | 生命周期状态 |
| `created` | 是 | ISO 日期 `2026-07-25` | 创建日期 |
| `tags` | 选填 | YAML 中写 `科研/算子空间`（不带 `#`） | 以领域开头；用于跨文件夹检索，不替代文件夹；正文内联标签才带 `#` |
| 其余 | 选填 | `semester` / `deadline` / `source` | 按需自加 |

源文件示例（`_meta/templates/笔记模板.md`）：

```yaml
---
type: note
status: active
created: 2026-07-25
---
```

## 标签规范（两级，以领域开头）

- frontmatter 最多两层：`科研/算子空间`、`教学/高等代数`、`家庭/运动`（不带 `#`）
- 正文内联标签使用 `#科研/算子空间`、`#教学/高等代数`、`#家庭/运动`
- 标签用于跨文件夹检索，**不替代文件夹层级**
- 领域前缀固定为三大域：`科研` / `教学` / `家庭`（新增领域对应新前缀，如 YAML 值 `行政/...`）

## 领域清单（顶层只增不改）

| 编号 | 领域 | 收纳范围 |
|------|------|---------|
| `00-inbox` | 收件箱 | 随手记，每周清空归位 |
| `10-科研` | 科研 | 课题、论文、学术阅读 |
| `20-教学` | 教学 | courses（按课程）+ students（按学生） |
| `30-家庭` | 家庭 | 孩子上学、学习、运动、健康 |
| `40-xxx`… | 新领域 | 学院行政、个人成长、阅读……（新增只增不改） |

## MOC 规范（手动维护）

- 根索引：`_meta/HOME.md` → 跳转到各域 `_MOC.md`
- 领域地图：每个领域根下有 `_MOC.md`，**手动维护、保持简短**
- 新增/删除笔记后，在对应 `_MOC.md` 追加/移除一行 `- [[笔记名]]`
- 不强制 Dataview；Obsidian graph 负责按 wikilinks + 标签聚簇

## Templates 规范

`_meta/templates/` 存放五类骨架，新建笔记前先复制对应模板：

| 模板 | 适用 |
|------|------|
| `笔记模板.md` | 通用笔记 `type: note` |
| `课程模板.md` | 课程首页 `type: course` |
| `课题模板.md` | 课题/论文首页 `type: project` |
| `人物模板.md` | 学生/孩子档案 `type: person` |
| `日志模板.md` | 日志流水 `type: log` |

模板文件本身不纳入领域 MOC 聚合。

## 命名与归档四条不变式

1. **顶层只放领域**：顶层目录 = 领域，编号 10 为步长；新领域 `40-xxx`，不改动已有。
2. **领域内新单元 = 新文件夹**：从 `_meta/templates/` 复制模板作为首页。
3. **归档不出领域**：完结内容进本领域 `_archive/` 或 `status: archived`。
4. **附件不出领域**：附件自动存当前笔记同级 `_attachments/`。

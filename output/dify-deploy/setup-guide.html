1安装 Docker Desktop

Docker 是运行 Dify 的基础环境

ℹ️
Docker Desktop for Windows 是官方提供的 Windows 版 Docker，自带 Docker Engine 和 Docker Compose。
  • ✓
    启用 WSL2：在安全中心将 WSL 添加到「系统级工具」白名单。或在「控制面板 → 程序 → 启用或关闭 Windows 功能」中勾选「适用于 Linux 的 Windows 子系统」和「虚拟机平台」，重启电脑。
  • ✓
    下载安装包：访问 Docker Desktop 官方下载（约 500MB），或从 官方文档页 获取最新版本。
  • ✓
    运行安装程序：双击下载的 Docker Desktop Installer.exe，按提示安装。安装时确保勾选「Use WSL 2 instead of Hyper-V」。
  • ✓
    启动 Docker Desktop：安装完成后启动应用。首次启动可能需要重启电脑。等待右下角 Docker 图标变为绿色（运行中）。
  • ✓
    验证安装：打开终端（Git Bash 或 PowerShell），运行以下命令确认 Docker 就绪：
docker --version # 应显示 Docker version 24.x+ docker compose version # 应显示 Docker Compose version v2.x+ docker info # 应显示 Server 信息，无报错

2部署 Dify 社区版

使用一键脚本克隆并启动 Dify 全部服务

🚀
已为你准备好一键部署脚本 deploy-dify.sh，位于 output/dify-deploy/ 目录。

在 Git Bash 中运行：

# 进入部署目录 cd "D:/赵亚菲/yafei-one-context/output/dify-deploy" # 运行一键部署脚本 bash deploy-dify.sh
⏳
首次启动耗时：脚本会从 Docker Hub 拉取约 5GB 镜像（nginx、weaviate、postgres、redis、sandbox、api、web 等），预计 5-15 分钟，取决于网络速度。如果拉取缓慢，可配置 Docker 镜像加速器。

启动成功后你会看到：

[OK] Docker 已就绪: Docker version 24.x [OK] 仓库克隆完成 [OK] .env 配置文件已生成 [INFO] 启动 Dify 服务... ... ======================================== Dify 访问地址 ======================================== Web 界面: http://localhost:3000 API 地址: http://localhost:5001 ========================================

3配置 LLM 模型

为智能体接入大语言模型，使其具备推理能力

🔑
Dify 支持多种 LLM 提供商。以下按推荐度排序，选择你有 API Key 的即可。
✅
推荐理由：国内访问无需代理，注册即送 14 元额度，支持多种开源模型，价格便宜。
  • ✓
    访问 硅基流动 注册账号
  • ✓
    进入「API 密钥」页面，创建新密钥并复制
  • ✓
    在 Dify 中：右上角头像 →「设置」→「模型供应商」→ 找到「SiliconCloud」→ 点击「设置」→ 粘贴 API Key
  • ✓
    推荐模型：LLM 用 deepseek-ai/DeepSeek-V3，Embedding 用 BAAI/bge-large-zh-v1.5
⚠️
注意：需要能访问 OpenAI API 的网络环境（代理/VPN）。
  • ✓
    访问 OpenAI API Keys 创建密钥
  • ✓
    在 Dify 中：设置 → 模型供应商 → OpenAI → 设置 → 粘贴 API Key
  • ✓
    推荐模型：LLM 用 gpt-4o-mini（便宜）或 gpt-4o，Embedding 用 text-embedding-3-small
✅
推荐理由：国内直连，中文能力强，有免费额度。
  • ✓
    访问 智谱开放平台 注册并获取 API Key
  • ✓
    在 Dify 中：设置 → 模型供应商 → 智谱 → 设置 → 粘贴 API Key
  • ✓
    推荐模型：LLM 用 glm-4-flash（免费）或 glm-4，Embedding 用 embedding-3
✅
推荐理由：阿里云出品，国内直连，有免费额度。
  • ✓
    访问 阿里云百炼 开通服务并获取 API Key
  • ✓
    在 Dify 中：设置 → 模型供应商 → 通义千问 → 设置 → 粘贴 API Key
  • ✓
    推荐模型：LLM 用 qwen-turbo（便宜）或 qwen-plus，Embedding 用 text-embedding-v2
❗
关键：必须同时配置 LLM 模型（用于对话推理）和 Embedding 模型（用于知识库向量化），缺一不可。知识库功能依赖 Embedding 模型。

4创建教学知识库

上传教学资料，构建可检索的知识库

上传文档
→
分段处理
→
Embedding 向量化
→
存入向量库
→
智能体检索
  • ✓
    进入知识库页面：Dify 主界面左侧导航 →「知识库」→ 点击「创建知识库」
  • ✓
    上传教学资料：支持 PDF、Word(.docx)、Markdown、TXT、Excel、CSV、HTML 等格式。可拖拽批量上传或从在线 URL 导入。
    建议：将课程讲义、教材章节、历年试卷、教学大纲等分批上传。
  • ✓
    配置分段策略（关键）：
    参数 推荐值 说明
    分段方式 自动分段（推荐）或自定义 自动适合大多数文档；结构化文档可手动设置
    分段长度 500-1000 字 中文建议 500 字左右，保证检索精度
    分段重叠 50-100 字 相邻分段重叠区域，避免切断语义
    索引方式 高质量索引（推荐） 使用 Embedding 模型向量化，检索更准
    检索模式 混合检索（推荐） 向量检索 + 全文检索，兼顾语义和关键词
    Top K 3-5 每次检索返回的分段数量
    Rerank 开启（如有模型） 对检索结果二次排序，提升精度
  • ✓
    选择 Embedding 模型：选择步骤 3 中配置的 Embedding 模型（如 bge-large-zh-v1.5 或 text-embedding-3-small）
  • ✓
    等待处理完成：Dify 会自动分段并向量化文档。处理时间取决于文档大小和 Embedding 模型速度。完成后会显示分段数量和状态。
  • ✓
    测试检索：在知识库详情页的「召回测试」中输入一个教学问题，验证是否能检索到相关内容。
💡
教学知识库建议包含：课程教材/讲义、教学大纲与知识点列表、常见学生提问及标准解答、历年试卷及解析、实验指导书、参考书目摘要。

5创建智能体并关联知识库

配置一个教学问答智能体，连接知识库实现 RAG 检索增强

  • ✓
    创建应用：Dify 主界面 →「创建空白应用」→ 选择「Agent（智能体）」→ 输入应用名称（如"教学问答助手"）
  • ✓
    选择 LLM：在右侧设置面板选择步骤 3 中配置的 LLM 模型（如 DeepSeek-V3 或 gpt-4o-mini）
  • ✓
    关联知识库：在「上下文」区域 → 点击「添加」→ 选择步骤 4 创建的教学知识库
  • ✓
    编写系统提示词：在「指令」区域填写智能体的角色设定和行为规则。参考下方模板：
# 教学问答助手 — 系统提示词模板 你是一位专业的教学问答助手，负责为学生解答课程相关问题。 ## 工作职责 1. 基于知识库中的教学内容，准确回答学生的问题 2. 回答时引用知识库中的具体内容，确保答案准确可靠 3. 如果知识库中没有相关信息，坦诚告知学生，不要编造答案 4. 用通俗易懂的方式解释复杂概念，必要时举例说明 ## 回答规范 - 回答使用中文 - 先给出直接答案，再展开解释 - 涉及公式时使用 LaTeX 格式 - 涉及代码时使用代码块 - 鼓励学生追问，引导深入理解 ## 限制 - 只回答与课程内容相关的问题 - 不提供考试答案的直接解答，而是讲解解题思路 - 保持学术严谨，不传播未经知识库验证的信息
  • ✓
    配置工具（可选）：根据需要添加工具，如「网页搜索」（联网搜索补充信息）、「数学计算」（处理数值问题）等
  • ✓
    调整模型参数：
    参数 推荐值 说明
    Temperature 0.3-0.6 较低值保证回答稳定一致
    Top P 0.9 控制生成多样性
    Max Tokens 2048 回答最大长度
    最大迭代次数 5-10 Agent 思考的最大轮次

6测试与发布

验证智能体效果，然后发布给学生使用

  • ✓
    调试对话：在 Dify 的「预览」区域与智能体对话，测试以下场景：
    • 知识库内有答案的问题 → 验证回答准确性
    • 知识库内无答案的问题 → 验证是否拒绝编造
    • 追问/多轮对话 → 验证上下文记忆
    • 模糊/口语化提问 → 验证意图理解
  • ✓
    发布应用：点击右上角「发布」按钮，应用上线
  • ✓
    分享给学生：发布后可获得一个 Web 访问链接，学生通过浏览器即可使用。也可通过 API 嵌入到其他系统。
🎉
完成！你的教学问答智能体已上线。学生打开分享链接即可向智能体提问，智能体会基于知识库内容给出准确回答。

7运维命令速查

Dify 服务的日常管理命令

操作 命令
查看服务状态 cd ~/dify/docker && docker compose ps
停止服务 cd ~/dify/docker && docker compose down
启动服务 cd ~/dify/docker && docker compose up -d
重启服务 cd ~/dify/docker && docker compose restart
查看日志 cd ~/dify/docker && docker compose logs -f
查看指定服务日志 cd ~/dify/docker && docker compose logs -f api
更新 Dify cd ~/dify && git pull && cd docker && docker compose pull && docker compose up -d
清理悬空镜像 docker image prune -f
💾
数据备份：Dify 数据存储在 Docker volumes 中（postgres、weaviate、redis）。备份时执行： cd ~/dify/docker && docker compose exec postgres pg_dump -U postgres dify > backup_$(date +%Y%m%d).sql

🔧 Docker 修复指南

3 步手动操作，解决 Windows Defender 权限问题

⚠️ 问题原因

Windows Defender 实时保护会锁定 Docker 创建的临时文件，导致 Docker Engine 无法启动。需要把 C:\Users\wucha\.docker 文件夹加入 Defender 排除列表。

1

打开 Windows 安全中心

按以下路径操作：

开始菜单 → 搜索"Windows 安全中心" → 打开

或者直接在任务栏右下角找到 🛡️ 盾牌图标，点击打开。

2

添加排除项

按以下路径依次点击：

Windows 安全中心
病毒和威胁防护
↓ 向下滚动找到
管理设置（在"病毒和威胁防护设置"下）
↓ 向下滚动到底部找到
排除项 → 添加或删除排除项
↓
+ 添加排除项 → 文件夹

在弹出的文件夹选择窗口中，输入或导航到：

C:\Users\wucha\.docker

点击"选择文件夹"。

3

启动 Docker Desktop

排除项添加完成后，从开始菜单启动 Docker Desktop，或者双击桌面图标。

等待 1-3 分钟，系统托盘右下角 Docker 图标变绿 🟢 就表示成功了。

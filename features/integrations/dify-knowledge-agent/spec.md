# Dify 知识库智能体 — 高校师生服务需求

## 背景

已远程部署 Dify 服务器，目标是构建基于知识库的智能体，为高校师生提供智能问答与服务。

## 目标用户

- 高校教师
- 高校学生（本科生、研究生）
- 行政管理人员（可选扩展）

## 核心需求

### 1. 知识库构建

- 汇聚校内各类制度、政策、流程文档（学籍管理、教务规定、科研政策、财务报销、后勤服务等）
- 支持多格式文档导入：PDF、Word、Markdown、网页、表格等
- 知识库按业务域分类（教务、科研、学工、后勤、财务、图书馆等）
- 支持知识库定期增量更新与版本管理

### 2. 智能问答能力

- 自然语言问答：师生用日常语言提问，智能体精准检索知识库并给出答案
- 多轮对话：支持上下文记忆，追问不丢失前文语义
- 引用溯源：回答附带来源文档及段落，方便核实
- 模糊问题引导：问题不明确时主动追问澄清
- 多语言支持（中英双语，视需求开放）

### 3. 典型应用场景

| 场景 | 说明 |
|------|------|
| 教务咨询 | 选课规则、学分要求、考试安排、成绩查询流程等 |
| 科研服务 | 项目申报流程、经费管理、成果登记、伦理审查等 |
| 学工事务 | 奖助学金申请、宿舍管理、社团审批、心理咨询预约等 |
| 后勤服务 | 校园卡充值、报修流程、食堂营业时间、班车时刻表等 |
| 图书馆 | 借阅规则、数据库使用、文献传递、查收查引等 |
| 就业指导 | 招聘信息、三方协议、档案去向、职业规划资源等 |

### 4. 接入渠道

- Web 网页端（嵌入学校门户 / 信息服务平台）
- 微信公众号 / 企业微信
- API 接口（供校内其他系统调用）

### 5. 管理与运维

- 后台管理面板：查看问答日志、热门问题统计、用户满意度
- 无效回答人工标注与知识库补全机制
- 对话记录脱敏处理，保护用户隐私
- 支持多租户或多校区独立配置（如需）

## 非功能性需求

- 响应延迟：95% 请求 < 3 秒
- 并发能力：支持高峰期 ≥ 500 QPS
- 可用性：≥ 99.9%
- 数据安全：校内数据不出校，敏感信息脱敏

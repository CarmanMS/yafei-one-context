# 概述

系统梳理 2021-08-30 至 2026-08-30 的两类文献：纯算子空间理论，以及算子空间与量子信息的实质性交叉。结合现有的 p-算子空间、局部反射性、映射理想、正合性与核性基础，寻找具备 JFA（*Journal of Functional Analysis*）级潜力且可先做可行性检验的研究问题。

“近期稿件均被顶刊拒绝”目前仅是用户陈述；知识库和 `paperwork` 未保存 decision letter 或 referee report，因此本需求不猜测拒稿原因。

# 目标与非目标

## 目标

- 建立可追溯、去重、带版本信息的近五年文献图谱。
- 区分纯算子空间与量子信息交叉，并排除仅把 Hilbert–Schmidt/Liouville 表示称为 “operator space” 的同名误命中。
- 精读高相关论文，记录主要结论、假设、证明依赖、局限和显式或隐含的开放问题。
- 将文献缺口与现有研究积累、在研稿件逐项比对，避免重复已有结果。
- 给出 3–5 个候选问题，并为最优方向设计短周期可证伪的起步检查。

## 非目标

- 不保证产生定理、被 JFA 接收或在固定期限内发表。
- 不把模型建议、未核实引用、猜想或数值现象写成已证明结论。
- 不在初筛阶段受时间、合作者或量子信息背景限制；这些只在候选方向排序后评估。
- 不在本规格阶段撰写论文、证明或实现完整实验。

# 用户与场景

算子空间研究者缺少下一篇论文方向，需要先看清近五年发展，再从“接近现有工具且可推进”与“交叉价值较高”之间做有证据的选择，而不是从宽泛关键词直接生成题目。

# 证据规则

- 文献事实以 DOI 页面、期刊页面、arXiv 版本和可核验原文为准，并记录检索日期。
- 已发表结论、作者猜想、本文推断和待核实断言必须分开标注。
- 每个候选问题都要列明符号、假设、关键前置定理和可能已被解决的检索证据。
- 若使用计算实验，必须保存代码、数据来源、环境和最小复现命令；实验不替代理论证明。

# 验收标准

- [ ] 保存检索日期、数据库、完整检索式和筛选规则；覆盖两条方向及滚动五年窗口。
- [ ] 文献表完成去重；每项含标题、作者、日期、版本、DOI/arXiv、方向分类和纳入/排除理由。
- [ ] 精读不少于 12 篇高相关论文且两条方向均有代表；若某方向不足 5 篇，记录检索证据和稀缺结论。
- [ ] 每篇精读记录核心结论、假设、证明工具、与现有工作的关系、限制及开放点。
- [ ] 形成 3–5 个候选问题；逐项标注已知/猜想/待核实状态、价值、创新性证据、JFA 适配度、主要障碍和失败风险。
- [ ] 对排名最高的两个方向给出首个引理或反例检查、2–4 周验证任务和明确的停止条件。
- [ ] 与 `paperwork/papers/` 中的既有成果和在研稿件交叉检查，避免把已有工作重新包装成新方向。
- [ ] 所有关键引用至少核验到论文原文或正式元数据；不以模型输出作为引用或证明。

# 风险、隐私与可复现

- 预印本和正式发表版本可能结论不同，必须固定版本并复核最新版。
- “开放问题”可能已在不同术语下解决；候选问题需做反向引文和同义词检索。
- 量子信息文献存在 “operator space” 同名异义，必须核验是否使用矩阵范数、完全有界映射或算子空间张量积框架。
- JFA 级潜力只能基于问题深度、创新性和现有证据评估，不能转化为录用概率保证。
- decision letter 和 referee report 若后续提供，应视为可能含隐私的本地材料，不进入公开 feature 全文。

# 开放问题

- 拒稿意见暂缺；后续若提供，只用于识别重复性风险、证明缺口或期刊匹配问题，不阻塞初始文献研究。
- 时间、合作方式和量子信息学习成本暂不参与初筛，待候选方向形成后再纳入排序。
- 纯算子空间与量子信息交叉两条线的最终优先级，由文献缺口和首轮可行性检查决定。

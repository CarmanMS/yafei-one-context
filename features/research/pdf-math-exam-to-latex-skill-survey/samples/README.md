## 快速诊断（2026-05-25）

- **非扫描件**：PyMuPDF 可抽出每页上千字符，含 `MATH1027`、`sin`、`dx`、题号「一、」等。
- **中文**：Windows 控制台常乱码，但 CJK 码位仍可匹配——不能依赖朴素 `pdftotext` 作终稿。
- **公式**：文本流里公式被拆成多行，**不是**可编译 LaTeX；需公式识别或整页 Vision OCR。
- **版式**：选择题、分值、装订线齐全，属典型大学数学期末卷。

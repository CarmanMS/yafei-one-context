# 技术方案 — p 算子空间 injective 性质文献研究

关联：`spec.md`

## 上下文与约束

- 检索应区分：**operator space injective**、**exact \(C^\*\)-algebra**、**\(W^\*\)-injective** 等与范畴内射相关的不同传统。
- 所有写入 `knowledge/references/` 的正文须含完整来源信息块（见 `knowledge/standards/one-context-conventions.md`）。

## 方案概览

1. **术语对齐**：用 1 页笔记列出英文检索式（如 `injective operator space`, `OH_p Pisier`, `noncommutative L_p injective`）。
2. **溯源**：从综述 MathSciNet / zbMATH / arXiv 分类 **OA（operator algebras）与 FA（functional analysis）** 交叉条目筛选。
3. **精读优先级**：先读定义 injective object 的章节 + 引用集中的 2–3 篇，再扩展横向对比。
4. **沉淀**：书目表 → 结构化 Markdown → 可选 Mermaid 概念图。

## 接口与数据

- 输入：开放访问 PDF / 机构订阅链接（用户自备）。
- 输出：feature 内草稿 + `knowledge/references/*.md` 终稿。

## 依赖与风险

- **风险**：同名 injective 多义；缓解——每篇笔记开头写明所用定义（书名/章节/公式编号）。
- **依赖**：无运行时依赖。

## 迁移与回滚

- 仅文档；回滚即 Git revert 对应 Markdown。

## 节目定位

面向 AI 工程师和架构师的中视频深度解析（8–12min），系统讲解 AI Agent 长期记忆的分层架构、核心流程、主流存储方案，以及阿里云四套长期记忆方案的选型对比与实践建议。

## 钩子

- **钩子**：Agent 80% 的失败是记忆污染导致的——错误的记忆比没有记忆更危险。阿里云一口气推出了四套长期记忆方案，到底怎么选？

## 章节摘要

1. **无状态的 LLM**：每次对话都从零开始，反复告诉 Agent "我偏好 TypeScript" 也会被遗忘。
2. **三层记忆架构**：短期（上下文窗口）/ 会话（任务中的中间状态）/ 长期（CLAUDE.md、memory）。
3. **存储方案对比**：向量库（语义召回）/ 知识图谱（关系约束）/ Markdown（人读 + AI 读）。
4. **阿里云四方案**：百炼长期记忆 API、RDS PostgreSQL、PolarDB Mem0、Polar Agent Memory；按规模、成本、可控性、运维复杂度选型。
